# Dataset Disclaimer

## About the Data

This project uses a **synthetic dataset** created for educational, development, and demonstration purposes.

The dataset was prepared using a combination of:

- Data adapted and combined from multiple publicly available datasets on **Kaggle**.
- Additional data that was **generated synthetically** to fill missing information and complete the required dataset structure.
- Data transformations and modifications performed specifically for this project.

## Important Notice

This dataset **does not represent real business data** and should not be considered an accurate representation of any real company, customer, transaction, or individual.

Any names, values, transactions, or other information contained in the dataset are either publicly sourced, modified, or artificially generated.

The dataset is intended solely for:

- Data analysis and visualization
- SQL and data engineering practice
- ETL/ELT pipeline development
- Data warehouse and BI development
- Testing and demonstration purposes
